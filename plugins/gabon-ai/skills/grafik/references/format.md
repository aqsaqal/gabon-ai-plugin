# Формат grafik.json

| Поле | Обяз. | Описание |
|---|---|---|
| `number`, `date` | да | Номер и дата документа |
| `object.name` | да | Объект |
| `start` | да | Дата начала. Первая работа начнётся в ближайший рабочий день |
| `company`, `brand` | нет | Реквизиты и фирменный стиль |
| `vor` | нет | Путь к vor.json для `vor_id` |
| `smeta` | нет | Путь к smeta.json для `smeta_pos` |
| `calendar.weekend` | нет | Маска выходных, по умолчанию `0000011` |
| `calendar.shifts_per_day` | нет | Смен в день, по умолчанию 1 |
| `calendar.shift_hours` | нет | Часов в смене, по умолчанию 8 |
| `calendar.holidays` | нет | Список дат `ГГГГ-ММ-ДД` |
| `calendar.holidays_source` | при праздниках | Основание списка |
| `tasks[]` | да | Работы в порядке показа |

## Работа

| Поле | Описание |
|---|---|
| `id` | Имя для связей, по умолчанию номер |
| `name` | Наименование; из ВОР или сметы, если не задано |
| `vor_id` / `qty` + `qty_source` + `unit` | Объём |
| `productivity` | `{ "per_shift": 250, "unit": "м3", "source": "…" }` — выработка одной бригады за смену |
| `crews` | Число бригад, по умолчанию 1 |
| `smeta_pos` | Номер позиции сметы «2.3»: берутся чел.-ч труда |
| `labor` | `{ "workers": 6, "hours": 311.04, "source": "…" }`; при `smeta_pos` только `workers` |
| `duration` + `duration_source` | Фиксированная длительность в днях |
| `milestone` | `true` — веха |
| `calendar_days` | `true` — считать календарными днями |
| `after` | Связи: `["id"]` или `[{"id": "...", "type": "FS" | "SS", "lag": 0}]` |
| `not_before` | Не раньше даты, например поставка материалов |
| `assumption`, `note` | Допущение и пояснение, печатаются в PDF |

## Правила расчёта

- Длительность = ОКРУГЛВВЕРХ(ОКРУГЛ(x; 6); 0): точное деление не прибавляет лишний день.
- FS: начало = следующий рабочий день после окончания предшественника + lag.
- SS: начало = начало предшественника + lag рабочих дней.
- Веха после FS-предшественника стоит в день его окончания.
- Резерв — в рабочих днях до позднего окончания без сдвига срока объекта. Резерв 0 — критический путь.
