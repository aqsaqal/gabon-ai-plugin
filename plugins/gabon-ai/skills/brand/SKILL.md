# Фирменный шаблон компании

Сначала прочитай общие правила GABON AI: `${CLAUDE_PLUGIN_ROOT}/rules/RULES.md`.

Оформление документов задаётся одним файлом `data/brand.json` в рабочей папке пользователя,
рядом с `company.json`. Логотип, шрифты и бланк лежат там же. В плагин их не кладут.
Скрипты в `scripts/` рядом с этим файлом.

## Команды

```bash
uv run ${CLAUDE_PLUGIN_ROOT}/skills/brand/scripts/brand.py init data/brand.json      # заготовка (не перезаписывает)
uv run ${CLAUDE_PLUGIN_ROOT}/skills/brand/scripts/brand.py check data/brand.json     # проверка
uv run ${CLAUDE_PLUGIN_ROOT}/skills/brand/scripts/brand.py preview data/brand.json --company data/company.json --out data/preview
```

`preview` собирает образец КП с условными данными и водяным знаком «ОБРАЗЕЦ», чтобы
пользователь посмотрел оформление до первого настоящего КП.

## Как настроить

1. Создай заготовку командой `init`.
2. Спроси у пользователя только то, что нужно для оформления:
   - логотип (PNG или JPG, лучше с прозрачным фоном);
   - фирменные цвета в виде #RRGGBB, если известны; иначе оставь стандартные;
   - есть ли фирменный бланк в PDF (шапка и подвал уже напечатаны);
   - стандартные условия КП: оплата, сроки, гарантия, срок действия.
3. Если есть бланк, укажи `letterhead_pdf` и подбери `margins_mm.top` и `bottom`, чтобы
   текст КП не наезжал на шапку и подвал бланка. Проверь это по `preview`.
4. Запусти `check`, затем `preview`, и покажи пользователю пути к образцам.
5. Подключи стиль к КП: в kp.json поле `"brand": "../data/brand.json"`.
   Для Excel-шаблона: `make_template.py ... --brand data/brand.json`,
   а при конвертации `xlsx_to_kp.py ... --brand data/brand.json`.

Формат и все поля: `references/format.md`.

## Правила

- Значения из kp.json всегда главнее значений из шаблона. Шаблон только дополняет
  пустые поля. Сборка КП печатает, что именно взято из шаблона.
- Ставки в `defaults.rates` допустимы только с источником (`vat_source` для НДС).
  Ставку НДС подтверждает бухгалтер.
- Не вставляй в шаблон изображения подписи или печати. Место для подписи остаётся пустым.
- Логотип и реквизиты другой компании (например, из присланного образца КП) используй
  только по прямому указанию пользователя.
