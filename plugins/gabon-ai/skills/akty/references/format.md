# Форматы навыка akty

## contract.json (создаётся make_contract.py, затем дополняется)

| Поле | Описание |
|---|---|
| `number`, `date` | Номер и дата договора |
| `subject`, `address` | Объект |
| `customer`, `contractor` | `name`, `bin`, `address`, `phone`, `signer_position`, `signer_name` |
| `vat_pct`, `vat_source` | НДС и основание |
| `amount_decimals` | Округление сумм: 2 или 0 |
| `positions[]` | `n`, `section`, `name`, `unit`, `qty` (по договору), `price` (без НДС, под ключ) |
| `totals` | `subtotal`, `vat`, `total` по договору |
| `advance` | `paid` (получено), `offset_pct` (% зачёта от суммы акта с НДС), `source` (пункт договора) |
| `retention` | `pct` (% от суммы акта с НДС), `source` |

## act.json

| Поле | Обяз. | Описание |
|---|---|---|
| `contract` | да | Путь к contract.json |
| `number`, `date` | да | Номер и дата акта. Дата не раньше конца периода |
| `period.from`, `period.to` | да | Отчётный период |
| `previous` | нет | Все предыдущие акты по договору (пути к act.json) |
| `lines[]` | да | Строки акта |
| `customer_materials` | нет | Сведения о давальческих материалах |
| `advance`, `retention` | нет | Если отличаются от договора |
| `sample` | нет | Водяной знак «ОБРАЗЕЦ» |

### Строка

| Поле | Обяз. | Описание |
|---|---|---|
| `n` | да | Номер позиции договора |
| `qty` | да | Фактически выполненный объём за период, > 0 |
| `evidence` | да | Документ, подтверждающий объём |
| `date` | нет | Дата выполнения, внутри периода |
| `report` | нет | Сведения об отчёте (графа 4 формы Р-1) |
| `overrun_reason` | при превышении | Доп. соглашение, если с начала работ объём больше договорного |

## Расчёт

- Стоимость строки = ОКРУГЛ(объём × договорная цена; 2).
- НДС = ОКРУГЛ(итого без НДС × ставка; 2).
- Зачёт аванса = МИН(ОКРУГЛ(итого с НДС × % зачёта; 2); остаток аванса).
- Удержание = ОКРУГЛ(итого с НДС × % удержания; 2).
- К оплате = итого с НДС − зачёт аванса − удержание.
