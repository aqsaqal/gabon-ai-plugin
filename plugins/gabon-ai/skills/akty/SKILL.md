# Акты выполненных работ

Сначала прочитай общие правила GABON AI: `${CLAUDE_PLUGIN_ROOT}/rules/RULES.md`.

Скрипты в `scripts/` рядом с этим файлом.

## Главные правила

1. **Только подтверждённые объёмы.** У каждой строки акта обязательно `evidence`:
   исполнительная схема, акт освидетельствования скрытых работ, запись журнала работ,
   ТТН, рапорт о работе машины. Объём без подтверждения в акт не включай: спроси пользователя.
   Объёмы из ВОР или графика — это план, а не факт.
2. **Подписи и печати не вставляются.** Только строки для подписи с должностью и ФИО.
3. **Договорные цены не меняются.** Акты считаются по замороженным ценам договора,
   а не по текущему прайсу.
4. **Превышение договорного объёма** допускается только с `overrun_reason` (доп. соглашение).
5. Форма Р-1 воспроизведена по приложению 50 к приказу Министра финансов РК № 562 от 20.12.2012.
   Перед первым использованием попроси бухгалтера сверить с действующей редакцией формы
   и требованиями заказчика. Если заказчик требует свою форму, сообщи об этом пользователю.

## Шаг 1. Договор (один раз)

```bash
uv run ${CLAUDE_PLUGIN_ROOT}/skills/akty/scripts/make_contract.py projects/<объект>/input/kp.json \
    --out projects/<объект>/input/contract.json --number <№ договора> --date ГГГГ-ММ-ДД
```

Скрипт фиксирует позиции и цены из согласованного КП. Накладные и прибыль включаются в
единичные цены. Разницу округления с итогом КП покажи пользователю. Затем заполни в
contract.json реквизиты заказчика (БИН, адрес, телефон, подписант) и, если есть в договоре,
`advance` (полученный аванс, % зачёта, пункт договора) и `retention` (% удержания, пункт).
Существующий contract.json скрипт не перезаписывает.

## Шаг 2. Акт за период

Создай `act_<N>.json` (формат: `references/format.md`, пример: `assets/act.example.json`):
номер, дата, период, строки «позиция договора — объём — подтверждение — дата».
В `previous` перечисли **все** предыдущие акты по договору.

```bash
uv run ${CLAUDE_PLUGIN_ROOT}/skills/akty/scripts/build_act.py projects/<объект>/input/act_<N>.json
uv run ${CLAUDE_PLUGIN_ROOT}/skills/akty/scripts/check_act.py <act.json> <AKT_....xlsx> <AKT_....pdf> <AKT_....docx>
```

Результат:
- **Excel**: лист «Акт» по форме Р-1 с формулами, «Накопительная» (по договору, ранее,
  за период, с начала, остаток, %), «Справка» (стоимость, зачёт аванса, удержание, к оплате);
- **PDF**: акт и справка с накопительной ведомостью и списком подтверждающих документов;
- **Word**: редактируемый акт.

Выдавать можно только при результате проверки «пройдена».

## Отчёт пользователю

Сумма за период без НДС, НДС, всего; зачёт аванса, удержание, к оплате; сколько выполнено
по договору с начала работ и остаток; позиции с превышением; список подтверждающих
документов, которые нужно приложить к акту.
