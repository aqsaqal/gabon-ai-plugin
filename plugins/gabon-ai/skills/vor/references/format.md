# Формат vor.json

| Поле | Обяз. | Описание |
|---|---|---|
| `number` | да | Номер ВОР |
| `date` | да | `ГГГГ-ММ-ДД` |
| `object.name` | да | Объект; `object.address` по желанию |
| `basis` | нет | Основание: ТЗ, проект, письмо |
| `company` | нет | Путь к company.json или объект |
| `brand` | нет | Путь к brand.json (навык brand) |
| `client` | нет | `{ "name": ... }`, переносится в КП |
| `qty_decimals` | нет | Знаков после запятой: 0–3, по умолчанию 2 |
| `documents[]` | нет | Исходные документы: `id`, `name`, `file`, `note` |
| `sections[]` | да | Разделы: `title` и `items[]` |
| `sample` | нет | `true` — водяной знак «ОБРАЗЕЦ» |

## Строка (`items[]`)

| Поле | Обяз. | Описание |
|---|---|---|
| `id` | нет | Имя для ссылок `@id`: буквы, цифры, `_`, точка. По умолчанию номер «1.2» |
| `name` | да | Наименование работы |
| `unit` | да | `м3`, `м2`, `п.м`, `т`, `шт`, … Записи `м³`, `кв.м` приводятся к стандарту |
| `formula` | * | Формула подсчёта: числа, `+ - × х * /`, скобки, `@id`. Запятая — десятичный знак |
| `qty` | * | Число из документа. Если есть и `formula`, они должны совпасть |
| `status` | нет | `подтверждено` (по умолчанию), `допущение`, `нет данных` |
| `ref` | ** | id документа из `documents` |
| `loc` | нет | Место в документе: страница, пункт, лист, ось |
| `source` | ** | Источник текстом, если документа нет в списке (например, «письмо заказчика от …») |
| `assumption` | для допущения | Что принято и кто подтверждает |
| `missing` | для «нет данных» | Каких данных не хватает |
| `note` | нет | Пояснение к подсчёту |
| `code` | нет | Код прайс-листа для перехода к КП |

\* нужен `formula` или `qty`, кроме статуса «нет данных», где нельзя указывать ни то, ни другое.
\** для статуса «подтверждено» нужен `ref` или `source`.

## Расчёт

- Результат каждой строки округляется до `qty_decimals` знаков по правилу «половина вверх».
- Ссылка `@id` берёт уже округлённое количество другой строки, так же как Excel.
- Ссылки на строки «нет данных», циклические ссылки, деление на ноль и количество ≤ 0 — ошибки.
- В Excel и PDF ссылки показываются номерами строк: `@бетон` → `п.2.4`.
