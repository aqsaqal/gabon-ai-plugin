# Проверка документов перед выдачей

Сначала прочитай общие правила GABON AI: `${CLAUDE_PLUGIN_ROOT}/rules/RULES.md`.

## Быстрая автоматическая проверка

```bash
uv run ${CLAUDE_PLUGIN_ROOT}/skills/proverka/scripts/review_project.py projects/<объект>
```

Проверяет все документы в input/ и output/ проекта:
- исходные данные каждого документа и независимый пересчёт Excel и PDF;
- файлы не устарели относительно исходных данных, прайса, ВОР, договора;
- нет тестовых данных в документах без пометки «образец»;
- в актах нет изображений (подписи и печати не вставляются);
- КП совпадает с текущим ВОР, строки ВОР без данных указаны в «Не включено»;
- акты учитывают все предыдущие, номера не повторяются; доля закрытия договора.

Отчёт пишется в `output/REVIEW_<дата>.md`. Код выхода 1 — есть блокирующие замечания.

## Независимая проверка

Для проверки перед отправкой заказчику поручи её агенту **proverka** этого плагина:
он не видел, как готовились документы, и проверяет только по файлам. Передай ему путь
к папке проекта.
Сам документы после его заключения не правь без решения пользователя: перескажи
пользователю вердикт и замечания, затем предложи исправления.
