# Прайс-лист компании

Сначала прочитай общие правила GABON AI: `${CLAUDE_PLUGIN_ROOT}/rules/RULES.md`.

Прайс-лист — единственный источник цен для КП и смет, если у позиции нет другого
подтверждённого источника. Скрипты лежат в `scripts/` рядом с этим файлом.

## Где лежит

`data/prices.xlsx` в рабочей папке пользователя (общий для всех объектов) или
`projects/<объект>/data/prices.xlsx` (цены только этого объекта). В плагин цены не кладутся.

## Формат

Лист «Прайс», колонки: Код | Наименование | Ед. изм. | Цена без НДС, тг | Вид затрат |
Источник | Дата цены | Примечание. Подробно: `references/format.md`.

## Команды

```bash
uv run ${CLAUDE_PLUGIN_ROOT}/skills/prices/scripts/prices.py template data/prices.xlsx   # пустой прайс
uv run ${CLAUDE_PLUGIN_ROOT}/skills/prices/scripts/prices.py check data/prices.xlsx      # проверка
uv run ${CLAUDE_PLUGIN_ROOT}/skills/prices/scripts/prices.py find data/prices.xlsx бетон В25
```

`template` не перезаписывает существующий файл.

## Как работать

1. **Создать прайс.** Сделай пустой файл командой `template` и предложи пользователю
   заполнить его. Если пользователь даёт прайсы поставщиков, КП или выгрузку из АВС-4,
   перенеси строки в прайс-лист, указывая в «Источнике» исходный документ, его номер и дату.
   Цены с НДС переводи в цены без НДС и пиши об этом в «Примечании».
2. **Проверить.** После любого изменения запусти `check`. Ошибки исправь вместе с пользователем.
   Устаревшие цены (старше 90 дней) перечисли пользователю и предложи актуализировать.
3. **Найти цену.** Используй `find`. Если совпадение неточное, покажи пользователю
   варианты и спроси, какой подходит. Не выбирай молча похожую расценку.
4. **Подставить в КП.** В kp.json укажи `price_list` и у позиций `code`.
   Навык `kp` сам подставит цену, единицу, вид затрат и источник с датой, а устаревшие цены
   попадут в замечания КП.
5. **Цена отличается от прайса** (скидка, договорённость): только с полем
   `price_override_reason`, где указана причина. Молча менять цену нельзя.

## Чего не делать

- Не добавляй в прайс цены без источника и даты.
- Не выдумывай и не «усредняй» цены. Нет цены — так и скажи и предложи запросить у поставщика.
- Цены из чужих КП-образцов не являются рыночными расценками: если их вносят, в источнике
  пиши «образец КП № … от …».
- Не меняй дату цены без новой подтверждённой цены.
