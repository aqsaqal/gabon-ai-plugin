# Формат прайс-листа

Файл Excel, лист «Прайс» (если его нет, берётся первый лист). Строка заголовков ищется
в первых 20 строках по колонкам «Код» и «Цена». Порядок колонок любой.

| Колонка | Обяз. | Правила |
|---|---|---|
| Код | да | Уникальный. Рекомендуемый вид: `ЗР-001` (земляные), `МН-` монолит, `ДМ-` демонтаж, `БЛ-` благоустройство, `КР-` кровля, `ОТ-` отделка, `ИС-` инженерные сети, `МТ-` материалы, `ТХ-` техника |
| Наименование | да | Как в КП |
| Ед. изм. | да | `м3`, `м2`, `п.м`, `т`, `шт`, `маш.-ч` и т. д. Записи `м³`, `м²`, `м.п` приводятся к стандарту автоматически |
| Цена без НДС, тг | да | Заголовок обязан содержать «без НДС». Число ≥ 0 |
| Вид затрат | да | `работа`, `материал`, `механизм`, `транспорт`, `комплекс`, `прочее` |
| Источник | да | Документ, из которого взята цена: прайс поставщика № и дата, КП, расчёт, экспорт АВС-4, решение руководства |
| Дата цены | да | Дата документа-источника. Формат даты Excel или `ДД.ММ.ГГГГ` |
| Примечание | нет | Например «пересчитано из цены с НДС» |

## Проверки

- **Ошибка** (строка не используется): нет кода, повтор кода, нет наименования, единицы,
  источника или даты, цена не число или отрицательная, неизвестный вид затрат.
- **Замечание**: нестандартная единица, нулевая цена.
- **Устарело**: цене больше 90 дней на дату проверки или дату КП. Порог меняется
  ключом `--max-age` или полем `price_max_age_days` в kp.json.

## Подстановка в КП

Позиция `{ "code": "МН-005", "qty": 86 }` получает из прайса цену, единицу, вид затрат,
наименование (если не задано) и источник вида
«Прайс-лист prices.xlsx, код МН-005, цена от 01.10.2026 (КП поставщика № 12)».
