# Форматы навыка smeta

## smeta.json

| Поле | Обяз. | Описание |
|---|---|---|
| `number`, `date` | да | Номер и дата `ГГГГ-ММ-ДД` |
| `object.name` | да | Объект |
| `company`, `brand` | нет | Реквизиты и фирменный стиль |
| `basis` | нет | Основание: ВОР, ТЗ, проект |
| `vor` | нет | Путь к vor.json: количества по `vor_id` |
| `cards` | нет | Путь к cards.json с калькуляциями |
| `price_list` | нет | Путь к прайс-листу для ресурсов с `code` |
| `price_max_age_days` | нет | Порог устаревания цен, по умолчанию 90 |
| `rates.overhead_pct` | да | Накладные, % |
| `rates.overhead_base` | нет | `direct` (по умолчанию) или `fot` |
| `rates.profit_pct` | да | Сметная прибыль, % |
| `rates.profit_base` | нет | `direct_overhead` (по умолчанию) или `fot` |
| `rates.vat_pct`, `rates.vat_source` | да | НДС и его основание |
| `rates.amount_decimals` | нет | 2 (по умолчанию) или 0 |
| `sections[]` | да | `title` и `positions[]` |

### Позиция

| Поле | Описание |
|---|---|
| `vor_id` | id строки ВОР: количество, наименование и единица берутся оттуда |
| `qty`, `qty_source` | Количество и его источник, если ВОР не используется |
| `card` | Код калькуляции из cards.json |
| `resources[]` | Ресурсы прямо в позиции, если калькуляции нет |
| `name`, `unit` | Если не взяты из ВОР или калькуляции |

### Ресурс

| Поле | Описание |
|---|---|
| `type` | `труд`, `машины`, `материал`, `транспорт` |
| `norm` | Расход на единицу работы, > 0 |
| `source` | Источник нормы (для калькуляции можно задать один `source` на карточку) |
| `code` | Код прайс-листа: цена, единица и наименование оттуда. Вид в прайсе должен соответствовать типу: труд → работа, машины → механизм |
| `name`, `unit`, `price`, `price_source` | Если цены нет в прайс-листе |

Количество ресурса = ОКРУГЛ(норма × кол-во позиции; 3). Сумма = ОКРУГЛ(кол-во ресурса × цена; 2).

## cards.json

```json
{ "cards": { "КЛ-МН-05": { "name": "Бетонирование ленты", "unit": "м3",
    "source": "Калькуляция компании № 12 от 01.09.2026",
    "resources": [ { "type": "материал", "code": "МН-005", "norm": 1.015 },
                   { "type": "труд", "code": "ТР-002", "norm": 0.6 } ] } } }
```

## contractor.json (результат import_estimate.py или ручной перенос из PDF)

```json
{ "contractor": "ТОО …", "source_file": "…", "prices_include_vat": false,
  "positions": [ { "row": 13, "n": "7", "section": "Бетонные работы", "name": "…", "unit": "м3",
                   "qty": "110", "price": "47000", "amount": "5170500", "code": "", "match": "2.3" } ],
  "totals": { "subtotal": "11206897", "vat": "1793103", "total": "13000000" } }
```

`match` — номер нашей позиции для ручного сопоставления (необязательно).

## Проверки документа подрядчика

- сумма строки ≠ кол-во × цена (допуск 1 тг);
- повтор позиции;
- «Итого» ≠ сумма строк; НДС ≠ ставка × итог; «Всего» ≠ итог + НДС;
- круглый итог при расхождении с пересчётом строк — признак подгонки.
